# HTML Authentication POC

This is a simple authentication flow created using only plain HTML.

## Pages Included

- login.html
- register.html
- forgot-password.html
- reset-password.html
- dashboard.html

## Flow

Login → Dashboard  
Register → Login  
Forgot Password → Reset Password → Login  

No CSS or JavaScript is used in this project.
This is only a structural authentication flow using anchor tag redirections.

Created for assignment submission.
